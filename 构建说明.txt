记忆卡片·每日待办 —— 安卓 APK 构建 / 安装 / 同步 说明
============================================================

本环境（WorkBuddy 沙盒）没有 Android 编译工具链，无法在这里直接产出 .apk。
以下是在你自己的电脑上把源码打包成可安装 APK 的步骤（只需做一次）。

------------------------------------------------------------
一、在电脑上出包（推荐用 WSL2 + Ubuntu，buildozer 官方只支持 Linux）
------------------------------------------------------------
1.  Windows 上安装 WSL2 + Ubuntu（开始菜单搜“启用或关闭 Windows 功能”勾选
    “虚拟机平台”“适用于 Linux 的 Windows 子系统”，重启后在 Microsoft Store 装 Ubuntu）。
2.  打开 Ubuntu 终端，安装依赖：
      sudo apt update
      sudo apt install -y python3-pip python3-venv git zip unzip openjdk-17-jdk
      pip3 install --user buildozer
3.  把本 android_app 文件夹整个复制到 Ubuntu 里（例如 ~/android_app）。
4.  进入目录：cd ~/android_app
5.  首次构建（会自动下载 Android SDK/NDK，约 10–30 分钟，需联网）：
      buildozer android debug
6.  成功后在本目录的 bin/ 下得到 memo_flashcard-1.0.0-arm64-v8a-debug.apk

提示：若想绕过 Linux，也可用“GitHub Actions + buildozer”云端出包（搜索
“buildozer github action”模板），但 WSL 路线最简单。

------------------------------------------------------------
二、安装到华为手机
------------------------------------------------------------
1.  把 bin/*.apk 传到手机（华为分享 / 数据线 / 微信文件传输助手均可）。
2.  手机：设置 → 安全 → 更多安全设置 → 开启“安装未知来源应用”（允许对应来源）。
3.  点击 apk 安装即可。华为 HarmonyOS 允许侧载，无需应用市场。

------------------------------------------------------------
三、可选：上架华为应用市场（AppGallery）
------------------------------------------------------------
若你确实要“应用市场能下载”，需自行走官方发布流程：
1.  注册华为开发者账号（https://developer.huawei.com/consumer/cn/），实名+缴费。
2.  在 AppGallery Connect 创建应用，上传签名后的 release APK/AAB。
3.  按华为审核要求补充隐私政策、备案等，审核通过后上架。
这一步必须你本人操作（涉及账号与资质），我无法代你完成。

------------------------------------------------------------
四、手机 ↔ 电脑 互相同步词库 / 待办（同一 Wi‑Fi）
------------------------------------------------------------
1.  电脑上双击“日常任务小程序\启动同步服务.bat”，窗口会显示
    “手机访问: http://<电脑IP>:8765/data”。保持该窗口打开。
2.  手机打开本 App → 切到“同步”页。
3.  点“发现并同步”：手机会自动在同一 Wi‑Fi 里发现电脑；若发现失败，
    手动填电脑的局域网 IP（如 192.168.1.23）再同步。
4.  同步逻辑：按 uid 合并，后修改的覆盖先修改的；删除也会双向传播。
    同步后两端词库与待办一致。

注意：电脑端“日常任务”桌面程序里删除的待办，不会自动传到手机
（桌面程序用物理删除）；在手机 App 里删除的会正常同步到电脑。

------------------------------------------------------------
文件清单（android_app/）
------------------------------------------------------------
- main.py            手机端 Kivy 界面（待办/记忆卡片/同步）
- task_store.py      待办数据层（与电脑端共用，已加同步字段）
- flashcard_store.py 卡片数据层（纯逻辑，含 uid/软删除）
- sync_core.py       双向合并 + Wi‑Fi 发现（纯逻辑，可单测）
- pc_sync_server.py  电脑端同步服务（位于上一级日常任务文件夹）
- buildozer.spec     APK 打包配置
- 启动同步服务.bat   电脑端同步服务启动器（位于上一级日常任务文件夹）
